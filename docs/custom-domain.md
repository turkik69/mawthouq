# نقل موثوق إلى دومينها الخاص

الواجهة تستخدم روابط داخلية نسبية، وملف `site.webmanifest` يبدأ من `index.html` بنطاق نسبي، كما يسجل `assets/auth.js` عامل الإشعارات من `sw.js` في مسار المنصة نفسه. يعيد رابط استعادة كلمة المرور المستخدم إلى `reset-password.html` على عنوان الصفحة الحالي. لا يلزم تثبيت اسم الدومين الجديد داخل الملفات الآن.

## عند اختيار الدومين

1. أضف الدومين المطلوب من إعدادات **GitHub Pages** لمستودع موثوق، ثم أضف سجلات DNS المطابقة لدى مسجل الدومين. اختر عنوانًا أساسيًا واحدًا، وفعّل HTTPS بعد اكتمال إعداد الشهادة. تحقق من ملكية الدومين لدى GitHub إذا أتاح الحساب ذلك. راجع [تعليمات GitHub للدومينات](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) و[HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https).
2. حدّث **Site URL** في Supabase Auth إلى العنوان الأساسي النهائي، وأضف روابط الإعادة الدقيقة للصفحات التي تستقبل التأكيد واستعادة كلمة المرور ضمن **Redirect URLs**. احتفظ بالرابط القديم مؤقتًا في القائمة خلال الانتقال ثم أزله بعد التأكد من عدم استخدامه. راجع [إعدادات روابط Supabase Auth](https://supabase.com/docs/guides/auth/redirect-urls).
3. اختبر إنشاء حساب جديد، رسالة تأكيد البريد، تسجيل الدخول والخروج، استعادة كلمة المرور، والموافقة على مقدم الخدمة على الدومين النهائي. لا تعتبر نجاح العرض وحده تأكيدًا على صلاحية روابط البريد.
4. ثبّت التطبيق مجددًا من الدومين النهائي واختبر إشعارات المتصفح هناك؛ صلاحيات المتصفح واشتراكات Push مرتبطة بعنوان المصدر ونطاق عامل الخدمة. اختبر الرسائل مع إغلاق صفحة المنصة. راجع [نطاق عامل الخدمة](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/register).
5. افحص جميع الصفحات القانونية والتواصل، والرابط الذي سيُرسل للعملاء، وأي روابط قديمة في البريد أو المواد التسويقية. حدّث بريد التواصل الرسمي عندما يصبح متاحًا. لا تفتح الدفع قبل إتمام تسجيل الجهة واعتماد الحساب البنكي وربط بوابة دفع واختبارها.

## تحقق سريع

- `https://<الدومين>/` يفتح الصفحة الرئيسية بلا تحذير شهادة.
- روابط التسجيل والطلبات والرسائل ولوحة المشرف لا تعود إلى مسار الموقع القديم.
- روابط البريد تستعيد الجلسة أو تقود إلى صفحة الاستعادة الصحيحة على الدومين الجديد.
- يظهر `site.webmanifest` و`sw.js` في نطاق الدومين الجديد؛ يطلب المتصفح إذن إشعارات جديدًا عند الحاجة.
