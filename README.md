# منصة موثوق

منصة دعم وخدمات أكاديمية — نسخة تعمل بتسجيل دخول وتسجيل حسابات حقيقية عبر Supabase (بدلًا من الأزرار التجريبية في النسخة الأصلية). حسابات مقسّمة إلى طالب خدمة / مقدم خدمة، مع عمولة منصة 10%.

## هيكل المشروع

```
mawthouq/
├── index.html               الصفحة الرئيسية
├── login.html                تسجيل الدخول
├── register.html              إنشاء حساب جديد
├── admin.html                 لوحة تحكم المشرف (تعرض كل المسجّلين)
├── site.webmanifest           يسمح بتثبيت الموقع كتطبيق على سطح المكتب (الشعار مضمّن بداخله)
├── assets/
│   ├── style.css                التنسيقات المشتركة لكل الصفحات
│   ├── supabase-config.js        بيانات الاتصال بـ Supabase (عدّليها أولاً — الخطوة 7 أدناه)
│   ├── auth.js                    منطق تسجيل الدخول / إنشاء الحساب / الجلسات
│   └── admin.js                    منطق لوحة تحكم المشرف
├── supabase/
│   └── schema.sql                قاعدة البيانات والصلاحيات — لا يُرفع كملف، بل يُنسخ محتواه ويُنفَّذ داخل Supabase (الخطوة 4)
└── README.md
```

**قاعدة سريعة:** ملف واحد فقط (`supabase/schema.sql`) وجهته Supabase، وباقي كل الملفات وجهتها GitHub.

## الجزء الأول: إعداد Supabase (~5 دقائق)

1. افتحي [supabase.com](https://supabase.com) وسجّلي دخول أو أنشئي حسابًا.
2. اضغطي **New Project**. اختاري اسمًا (مثلاً mawthouq)، وكلمة مرور لقاعدة البيانات (احفظيها في مكان آمن)، والمنطقة، ثم أنشئي المشروع. انتظري دقيقتين تقريبًا حتى يجهز.
3. من القائمة الجانبية افتحي **SQL Editor** → **New query**.
4. افتحي ملف `supabase/schema.sql` (من الملفات اللي عندك)، انسخي محتواه بالكامل، الصقيه في المحرر، واضغطي **Run**.
5. من القائمة الجانبية: **Authentication → Providers → Email**، أوقفي خيار **Confirm email**، ثم احفظي.
6. من **Project Settings → API**، انسخي القيمتين: **Project URL** و**anon public key**.
7. افتحي `assets/supabase-config.js` على جهازك، واستبدلي القيمتين الحاليتين بما نسختِه، ثم احفظي الملف.

بهذا انتهى الجزء الخاص بـ Supabase — لا حاجة ترجعين له إلا عند الترقية لمشرف في الخطوة الأخيرة.

## الجزء الثاني: الرفع على GitHub (~5 دقائق)

1. افتحي [github.com](https://github.com) وسجّلي دخول أو أنشئي حسابًا.
2. اضغطي **+** أعلى الصفحة → **New repository**. اختاري اسمًا (مثلاً mawthouq)، واختاري Public (لتقدري تفعّلين رابطًا مجانيًا لاحقًا)، ثم **Create repository**.
3. بصفحة المستودع الفارغة، اضغطي رابط **uploading an existing file**.
4. اسحبي **مجلد mawthouq كاملاً** (بما فيه مجلدي assets وsupabase) إلى منطقة الرفع — جيت‌هَب يحافظ على ترتيب المجلدات تلقائيًا.
5. انزلي تحت، اكتبي رسالة بسيطة مثل "رفع أولي"، واضغطي **Commit changes**.

### تفعيل رابط مباشر للموقع (اختياري لكن يُنصح به)
1. بصفحة المستودع: **Settings → Pages**.
2. تحت Source اختاري الفرع **main** والمجلد **/ (root)**، ثم **Save**.
3. انتظري دقيقة، وبيظهر لك رابط بصيغة `username.github.io/mawthouq` — هذا رابط منصتك المباشر.

## الجزء الثالث: التجربة وإنشاء حساب المشرف

1. افتحي الرابط (أو افتحي `index.html` من جهازك مباشرة) واضغطي **إنشاء حساب**.
2. سجّلي بهذه البيانات:
   - اسم المستخدم: `فهد اليحيائي`
   - كلمة المرور: `F96680303M`
   - أي بريد إلكتروني ورقم هاتف، ونوع الحساب أيهما تفضّلين (لا يمنع صلاحية المشرف لاحقًا)
3. ارجعي إلى `SQL Editor` في Supabase ونفّذي:
   ```sql
   update public.profiles set is_admin = true where username = 'فهد اليحيائي';
   ```
4. سجّلي دخول من جديد بنفس البيانات — بيظهر لك رابط **لوحة التحكم** في الترويسة.

## ملاحظة أمنية مهمة

كلمة مرور المشرف **لم تُدرَج كنص صريح في أي ملف كود**. الحساب يُنشأ عبر نظام مصادقة Supabase نفسه (الذي يخزّن كلمات المرور مشفّرة)، لا عبر شرط مكتوب في جافاسكربت. مفتاح `anon key` في `supabase-config.js` **آمن للنشر العلني**؛ المفتاح الذي يجب ألا يظهر أبدًا في كود الواجهة الأمامية هو `service_role key`.

رقم الحساب البنكي لمقدمي الخدمة يُخزَّن كنص مباشر في القاعدة — مناسب للمرحلة الحالية، لكن عند التوسع الفعلي بمدفوعات حقيقية الأفضل عالميًا استخدام بوابة دفع (Payouts) بدل التخزين المباشر.

## قابلية التوسع لاحقًا

- تعديل الملف الشخصي، واسترجاع كلمة المرور، وأكثر من مشرف واحد — الأساس جاهز لإضافتها متى احتجتها.
- قسم "اطلب خدمة" (نموذج الطلب) ما زال يحفظ الطلب تجريبيًا فقط دون قاعدة بيانات؛ أخبريني إن أردتِ ربطه وتخزين الطلبات الحقيقية.
